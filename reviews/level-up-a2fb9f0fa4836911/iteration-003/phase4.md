## Executable acceptance requirements

Each implementation slice must add exact-code negative and positive tests:

- installed or preflighted checker bytes/version mismatch;
- detached packet/result/contract digest mutation and self-reference exclusion;
- stale/sibling gate ancestry, non-conformant gate result, ambiguous replacement generation;
- foreign-run rows in every child table and total coverage without a complete manifest;
- verification-only/halted empty effects and completed planned work;
- Windows drive/case/reserved collisions, links/reparse points, unreadable and non-UTF-8 artifacts;
- advisory empty minimum, cross-adjudication IDs, CLI exits and execution receipt;
- generator drift/unknown sentinel/interrupted commit recovery;
- Bash exit 18 and exact lane coverage;
- Windows case-only target identity.
